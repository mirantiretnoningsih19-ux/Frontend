
# Frontend Data Siswa

Project frontend untuk aplikasi pengelolaan data siswa menggunakan React dan Vite.

## Teknologi
- React.js
- Vite
- JavaScript
- CSS

## Fitur
- Menampilkan daftar siswa
- Menambahkan data siswa
- Mengedit data siswa
- Menghapus data siswa
- Form input data siswa

## Struktur Folder
text

src/
App.jsx
main.jsx
style.css
index.html
package.json
vite.config.js

## Cara Menjalankan

1. Pastikan backend dan MySQL sudah berjalan.
2. Buka terminal di folder frontend.
3. Install package:

bash
npm install

4. Jalankan aplikasi:

```bash
npm run dev
```

5. Buka alamat berikut di browser:

http://localhost:5173

## Koneksi Backend

Frontend terhubung dengan backend melalui API:

http://localhost:3000/api/siswa

## Data Siswa

Data yang dikelola dalam aplikasi:

- Kode Siswa
- Nama Siswa
- Alamat Siswa
- Tanggal Siswa
- Jurusan Siswa
